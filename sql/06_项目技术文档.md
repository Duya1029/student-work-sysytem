# 学生作业管理系统 - 项目技术文档

## 一、项目概述

### 1.1 项目简介
学生作业管理系统是一个基于 B/S 架构的 Web 应用，实现管理员、教师、学生三种角色的作业管理全流程，包括作业发布、提交、批改打分、账号班级管理等功能。

### 1.2 功能角色

| 角色 | 功能说明 |
|------|---------|
| 管理员 | 登录、管理账号、管理班级、查看全部作业记录 |
| 教师 | 登录、发布作业、批改打分评语、查看提交列表 |
| 学生 | 登录、查看作业、提交作业、查看分数评语 |

sys_user (用户表)

sys_homework (作业表)
   │
   ├── teacher_id (外键) → sys_user

sys_submission (提交表)

## 五、核心流程说明

### 5.1 认证流程
```
1. 用户登录 → POST /api/login
2. 后端校验用户名密码 → 生成 JWT Token
3. 前端保存 Token 到 localStorage
4. 后续请求携带 Authorization: Bearer {token}
5. JwtInterceptor 拦截校验 Token
6. Token 有效 → 放行，无效 → 返回 401
```

### 5.2 教师发布作业流程
```
1. 教师登录 → 跳转首页
2. 点击"发布作业" → 填写作业信息
3. POST /api/teacher/homework/publish
4. 后端 Service → Mapper → SQL Server
5. 发布成功 → 跳转作业列表
```

### 5.3 学生提交作业流程
```
1. 学生登录 → 跳转首页
2. 点击"我的作业" → 查看作业列表
3. 点击"查看详情" → 获取作业详情
4. 填写作业内容 → 提交
5. POST /api/student/homework/submit
6. 后端检查是否已提交 → 新增或更新
```

### 5.4 教师批改流程
```
1. 教师登录 → "我的作业"
2. 点击"批改" → 查看提交列表
3. 点击某学生的"批改"按钮
4. 输入分数和评语 → 确认
5. PUT /api/teacher/homework/grade
6. 后端更新 submission 表的 score, comment, grade_time
```

## 六、部署指南

### 6.1 环境准备
1. **JDK 17**：安装并配置 JAVA_HOME
2. **Node.js 18+**：安装用于前端构建
3. **Maven 3.9+**：用于后端依赖管理
4. **SQL Server 2022 + SSMS 22**：数据库
5. **Nginx 1.24**：反向代理

### 6.2 数据库部署
1. 打开 SSMS，连接到 SQL Server 实例
2. 打开 `03_建表SQL.sql` 文件
3. 执行脚本，创建数据库和表
4. 验证测试数据

### 6.3 后端部署
1. 修改 `application.yml` 中数据库连接信息
   ```yaml
   url: jdbc:sqlserver://localhost:1433;databaseName=homework_db;encrypt=false;trustServerCertificate=true
   username: sa
   password: 你的密码
   ```
2. Maven 打包：
   ```powershell
   cd 后端\homework-system
   mvn clean package
   ```
3. 启动：
   ```powershell
   java -jar target/homework-system-1.0.0.jar
   ```
4. 验证：访问 http://localhost:8080/api/user/info

### 6.4 前端部署
1. 安装依赖：
   ```powershell
   cd 前端\homework-frontend
   npm install
   ```
2. 开发模式运行：
   ```powershell
   npm run dev
   ```
3. 打包构建：
   ```powershell
   npm run build
   ```
4. 将 dist 目录部署到 Nginx

### 6.5 Nginx 部署
1. 安装 Nginx 到 C:\nginx
2. 复制 `04_nginx配置/nginx.conf` 到 C:\nginx\conf\
3. 修改配置中前端资源路径
4. 启动 Nginx：
   ```powershell
   cd C:\nginx
   start nginx
   ```
5. 访问 http://localhost

### 6.6 启动顺序
1. 启动 SQL Server 服务
2. 启动后端 Spring Boot（端口 8080）
3. 启动 Nginx（端口 80）
4. 浏览器访问 http://localhost
