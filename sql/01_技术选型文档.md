# 学生作业管理系统 - 技术选型文档

## 一、项目概述

本项目为基于 B/S 架构的学生作业管理系统，支持管理员、教师、学生三种角色，实现作业发布、提交、批改打分、账号班级管理等功能。

## 三、前端技术详解

### 3.1 Vue 3 + Composition API
- **选择理由**：Composition API 提供更灵活的逻辑组织与复用能力，TypeScript 支持更友好。
- **项目结构**：基于 Vite 脚手架创建，采用 `<script setup>` 语法糖。

### 3.2 Element Plus
- **选择理由**：Vue 3 生态中最成熟的 UI 组件库，组件丰富、文档完善，适合管理后台。
- **常用组件**：Form、Table、Dialog、Menu、Pagination、Message、MessageBox 等。

### 3.3 Vue Router 4
- **选择理由**：官方路由方案，支持懒加载、导航守卫、动态路由。
- **路由守卫**：基于角色（role）进行登录校验与权限拦截。

### 3.4 Pinia
- **选择理由**：Vue 3 官方推荐的状态管理库，API 简洁，TypeScript 支持优秀。
- **主要 Store**：用户信息、权限令牌。

### 3.5 Axios
- **选择理由**：Promise 风格，支持请求/响应拦截器，便于统一处理 Token 与错误。

## 四、后端技术详解

### 4.1 Spring Boot 3.2
- **选择理由**：约定优于配置，内嵌 Tomcat，开箱即用，适合快速构建 RESTful API。
- **Java 版本要求**：Spring Boot 3.x 最低要求 JDK 17，与本项目 JDK 17 完美匹配。

### 4.2 Spring MVC
- **选择理由**：Spring 的 Web 层框架，基于 DispatcherServlet，支持 `@RestController`、`@GetMapping` 等注解，开发 RESTful 接口高效。
- **请求处理流程**：
  1. 客户端请求 → DispatcherServlet
  2. HandlerMapping 找到对应 Controller
  3. Controller 处理请求返回数据
  4. 通过 MessageConverter 转换 JSON 响应

### 4.3 MyBatis
- **选择理由**：SQL 与 Java 代码分离，XML 映射文件管理 SQL，灵活度高，便于 SQL 优化。
- **集成方式**：MyBatis-Spring-Boot-Starter，通过 `@MapperScan` 扫描 Mapper 接口。
- **配置方式**：SQL 语句写在 `*Mapper.xml` 文件中，接口与 XML 一一对应。

## 五、数据库选型

### 5.1 SQL Server 2022 + SSMS 22
- **选择理由**：用户指定，企业级关系型数据库，与 Windows 环境集成良好。
- **连接驱动**：`mssql-jdbc`（Microsoft 官方 JDBC 驱动）。
- **字符集**：使用 `NVARCHAR` 存储 Unicode 字符，避免中文乱码。

### 5.2 表结构设计
| 表名 | 说明 |
|------|------|
| sys_user | 用户表（管理员/教师/学生） |
| sys_class | 班级表 |
| sys_homework | 作业表 |
| sys_submission | 作业提交表 |

## 六、服务器配置

### 6.1 Nginx（反向代理）
- **作用**：
  - 前端静态资源托管（Vue 打包后的 dist 目录）
  - 反向代理后端 API 请求（`/api/**` → `http://localhost:8080`）
  - 解决跨域问题
- **监听端口**：80

### 6.2 Tomcat（后端容器）
- **作用**：运行 Spring Boot 打包后的 war/jar，提供 RESTful API 服务。
- **内嵌方式**：Spring Boot 内嵌 Tomcat，默认端口 8080。
- **外部部署（可选）**：如需外部 Tomcat 部署，需将打包方式改为 war 并继承 `SpringBootServletInitializer`。

## 七、开发与部署流程

### 7.1 开发环境
1. 前端：VSCode + Node.js 18+ + Vite
2. 后端：IDEA / VSCode + JDK 17 + Maven
3. 数据库：SQL Server 2022 + SSMS 22

### 7.2 部署流程
1. 前端执行 `npm run build` 生成 dist 目录
2. 后端执行 `mvn package` 生成 jar 包
3. 启动后端：`java -jar homework.jar`
4. 配置 Nginx 指向前端 dist 与后端 8080 端口
5. 启动 Nginx：`nginx` 或 `start nginx`

## 八、端口规划

| 服务 | 端口 | 说明 |
|------|------|------|
| 前端 (Nginx) | 80 | 静态资源 + 反向代理入口 |
| 后端 (Tomcat) | 8080 | Spring Boot API 服务 |
| SQL Server | 1433 | 数据库默认端口 |

## 九、总结

本系统采用前后端分离架构，前端 Vue 3 + Element Plus 负责页面渲染与交互，后端 Spring Boot 3 + MyBatis + Spring MVC 提供 RESTful API，SQL Server 2022 存储数据，Nginx 做反向代理统一入口，Tomcat 运行后端服务，整体结构清晰、便于维护与扩展。
