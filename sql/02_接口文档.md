# 学生作业管理系统 - 接口文档

> 基础路径：`/api`
> 请求/响应格式：`application/json`
> 统一响应体结构：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

> 状态码说明：200-成功，400-参数错误，401-未登录，403-无权限，500-服务器错误

---

## 一、公共接口

### 1.1 用户登录

- **接口**：`POST /api/login`
- **描述**：管理员/教师/学生统一登录入口，根据角色返回不同信息
- **请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 用户名 |
| password | String | 是 | 密码 |

- **请求示例**：
```json
{
  "username": "admin",
  "password": "123456"
}
```

- **响应示例**：
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "userId": 1,
    "username": "admin",
    "realName": "系统管理员",
    "role": "ADMIN",
    "classId": null,
    "className": null,
    "token": "Bearer eyJhbGciOiJIUzI1NiJ9..."
  }
}
```

### 1.2 退出登录

- **接口**：`POST /api/logout`
- **描述**：退出登录，清除 Token
- **请求头**：`Authorization: Bearer {token}`
- **响应示例**：
```json
{
  "code": 200,
  "message": "退出成功",
  "data": null
}
```

### 1.3 获取当前用户信息

- **接口**：`GET /api/user/info`
- **描述**：获取当前登录用户信息
- **请求头**：`Authorization: Bearer {token}`
- **响应示例**：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "userId": 1,
    "username": "admin",
    "realName": "系统管理员",
    "role": "ADMIN",
    "classId": null,
    "className": null
  }
}
```

## 二、管理员接口

### 2.1 班级管理

#### 2.1.1 班级列表（分页）

- **接口**：`GET /api/admin/class/list`
- **描述**：分页查询班级列表
- **请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| pageNum | int | 否 | 页码，默认 1 |
| pageSize | int | 否 | 每页条数，默认 10 |
| className | String | 否 | 班级名称（模糊查询） |

- **响应示例**：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "total": 5,
    "list": [
      {
        "classId": 1,
        "className": "计算机科学与技术2022-1班",
        "studentCount": 30,
        "createTime": "2024-09-01T10:00:00"
      }
    ],
    "pageNum": 1,
    "pageSize": 10
  }
}
```

#### 2.1.2 新增班级

- **接口**：`POST /api/admin/class/add`
- **请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| className | String | 是 | 班级名称 |

- **请求示例**：
```json
{
  "className": "软件工程2022-1班"
}
```

- **响应示例**：
```json
{
  "code": 200,
  "message": "新增成功",
  "data": null
}
```

#### 2.1.3 修改班级

- **接口**：`PUT /api/admin/class/update`
- **请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| classId | Long | 是 | 班级 ID |
| className | String | 是 | 班级名称 |

- **请求示例**：
```json
{
  "classId": 1,
  "className": "计算机2022-1班"
}
```

#### 2.1.4 删除班级

- **接口**：`DELETE /api/admin/class/delete/{classId}`
- **路径参数**：`classId` - 班级 ID

### 2.2 账号管理

#### 2.2.1 账号列表（分页）

- **接口**：`GET /api/admin/user/list`
- **请求参数**：

| 参数名 | 类型 | 必填 | 说明 |

- **响应示例**：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "total": 50,
    "list": [
      {
        "userId": 2,
        "username": "teacher01",
        "password": "****",
        "realName": "张老师",
        "role": "TEACHER",
        "classId": null,
        "className": null,
        "createTime": "2024-09-01T10:00:00"
      }
    ],
    "pageNum": 1,
    "pageSize": 10
  }
}
```

#### 2.2.2 新增账号

- **接口**：`POST /api/admin/user/add`
- **请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 用户名 |
| password | String | 是 | 密码 |
| realName | String | 是 | 真实姓名 |
| role | String | 是 | 角色：ADMIN/TEACHER/STUDENT |
| classId | Long | 否 | 班级 ID（学生必填，教师/管理员为空） |

#### 2.2.3 修改账号

- **接口**：`PUT /api/admin/user/update`
- **请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userId | Long | 是 | 用户 ID |
| username | String | 是 | 用户名 |
| password | String | 否 | 密码（为空则不修改） |
| realName | String | 是 | 真实姓名 |
| role | String | 是 | 角色 |
| classId | Long | 否 | 班级 ID |

#### 2.2.4 删除账号

- **接口**：`DELETE /api/admin/user/delete/{userId}`
- **路径参数**：`userId` - 用户 ID

#### 2.2.5 重置密码

- **接口**：`PUT /api/admin/user/resetPwd`
- **请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userId | Long | 是 | 用户 ID |
| newPassword | String | 是 | 新密码 |

## 三、教师接口

### 3.1 发布作业

- **接口**：`POST /api/teacher/homework/publish`
- **请求头**：`Authorization: Bearer {token}`
- **请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| title | String | 是 | 作业标题 |
| description | String | 是 | 作业描述 |
| classId | Long | 是 | 班级 ID |
| deadline | String | 是 | 截止时间（yyyy-MM-ddTHH:mm:ss） |

- **请求示例**：
```json
{
  "title": "第二次作业",
  "description": "完成第二章习题1-10",
  "classId": 1,
  "deadline": "2024-09-20T23:59:59"
}
```

### 3.2 查看我的作业列表

- **接口**：`GET /api/teacher/homework/list`
- **请求头**：`Authorization: Bearer {token}`
- **请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| pageNum | int | 否 | 页码，默认 1 |
| pageSize | int | 否 | 每页条数，默认 10 |

### 3.3 查看作业提交列表

- **接口**：`GET /api/teacher/homework/submissions/{homeworkId}`
- **请求头**：`Authorization: Bearer {token}`
- **路径参数**：`homeworkId` - 作业 ID

### 3.4 批改作业打分评语

- **接口**：`PUT /api/teacher/homework/grade`
- **请求头**：`Authorization: Bearer {token}`
- **请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| submissionId | Long | 是 | 提交记录 ID |
| score | int | 是 | 分数（0-100） |
| comment | String | 否 | 评语 |

- **请求示例**：
```json
{
  "submissionId": 1,
  "score": 90,
  "comment": "思路清晰，答案准确，表现优秀！"
}
```

### 3.5 查看我的班级

- **接口**：`GET /api/teacher/classes`
- **请求头**：`Authorization: Bearer {token}`
- **描述**：获取当前教师可管理的班级列表
